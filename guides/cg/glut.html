Understanding window management, callback registration, and main event loops.

What is GLUT?

The **OpenGL Utility Toolkit (GLUT)** is a system-independent library for handling window creation, user keyboard/mouse events, and screen refresh loop triggers. It hides OS-specific window management tasks.

Event Loop & Hooks

User interactions are captured via event handler hooks: - `glutMouseFunc(myMouse)`: Clicks (DOWN/UP, LEFT/RIGHT). - `glutMotionFunc(myMotion)`: Clicks & drags. - `glutKeyboardFunc(myKeyboard)`: Key taps. - `glutMainLoop()`: Starts the infinite OS event monitoring execution.
